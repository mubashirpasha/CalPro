## 🚀 About CalcPro

**CalcPro** is a modern and premium calculator workspace built using HTML5, CSS3, and Vanilla JavaScript.

It combines standard calculations, advanced scientific functions, percentage tools, BMI calculations, age calculations, and unit conversions in one beautiful interface.

Designed with a responsive layout, dark and light themes, calculation history, and offline-ready PWA functionality, CalcPro delivers a smooth experience across mobile, tablet, and desktop devices.

## 🚀 Installation & Setup

### Requirements

- Modern web browser.
- Python 3 (for local server) or another static HTTP server.
- Git (optional).

### 1. Clone Repository

```bash
git clone https://github.com/YOUR-USERNAME/CalcPro.git
```

### 2. Open Project Folder

```bash
cd CalcPro
```

### 3. Run Locally

You can directly open `index.html` in your browser.

For service worker and offline functionality, use a local server:

```bash
python -m http.server 3000
```

### 4. Open in Browser

```text
http://localhost:3000
```

That's it! Your CalcPro application is ready.

## 🌍 Deployment

CalcPro is a static website, so it can be deployed easily.

### Supported Platforms

- **Netlify:** Drag and drop the project folder or connect GitHub.
- **Vercel:** Import the repository as a static website.
- **GitHub Pages:** Enable GitHub Pages from repository settings.

| Configuration | Value |

## 🔐 Privacy & Security

Privacy is a core part of CalcPro.

- Calculations run directly in the browser.
- No backend or database is required.
- Calculation history is stored locally when browser storage is available.
- No external API keys are needed.
- No third-party scripts or analytics are included.
- Mathematical expressions are evaluated using a safe custom parser rather than JavaScript `eval()`.

## 📲 Progressive Web App (PWA)

CalcPro includes PWA capabilities:

- Application manifest.
- Custom application icons.
- Service worker.
- App-shell caching.
- Installability on supported browsers.
- Offline access to cached application resources.
